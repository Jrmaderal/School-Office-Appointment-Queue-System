# INDIVIDUAL NARRATIVE REPORT

**Project Title:** School Queue
**Subject:** Event-Driven Programming
**Student:** Jerome R. Martinez
**Section:** BSIT-3C
**Assigned Role:** Backend Developer and System Integration

## Individual Contribution

As a member of the development team, my primary responsibility was the backend development and system integration of the School Queue. While my group member focused on developing the frontend interface, I was responsible for connecting the existing interface to the backend and implementing the core system transactions.

During the development process, I configured the backend environment using Node.js and Express.js and integrated SQLite as the system database. I implemented REST API endpoints that enabled communication between the frontend and backend, allowing the system to process and manage queue-related transactions.

One of my major contributions was the integration of Socket.IO to establish real-time communication between the student and staff dashboards. Through this implementation, queue information could be updated automatically whenever a transaction occurred without requiring users to manually refresh the page.

I also worked on the core functionalities of the system, including queue ticket generation, calling the next student, serving tickets, skipping tickets, cancelling requests, and transferring tickets between school offices. These functionalities demonstrated the application of event listeners, asynchronous processing, REST API communication, and WebSocket technology.

Throughout the development process, I encountered several technical challenges, including API integration errors, invalid queue statuses, and real-time connection issues. I addressed these challenges through debugging, testing, and AI-assisted technical guidance. I also worked on basic backend authentication, including database-based login verification, password hashing, and session management.

Furthermore, I assisted in preparing the final project files and providing instructions for installing the necessary dependencies and running the system on another computer.

Through this project, I gained a better understanding of backend development, database management, REST API integration, WebSocket communication, and the practical application of Event-Driven Programming. This experience also strengthened my problem-solving, debugging, and system integration skills.

Overall, my contribution focused on transforming the existing frontend interface into a functional system capable of processing queue transactions and delivering real-time updates between users.
